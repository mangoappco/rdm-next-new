Componentes

Acción

  • touch_app
    Button Los botones ayudan a las personas a realizar acciones como enviar un correo, compartir un documento o dar like a un comentario.
  • radio_button_checked
    Icon button Los botones de icono permiten realizar acciones con un solo toque.
  • view_day
    Button group Los botones puestos en fila, con su separación fijada por el sistema.
  • add
    FAB Botón de acción principal de una pantalla.
  • add_circle
    FAB extended FAB con etiqueta de texto.
  • segment
    Segmented button El grupo de segmentos ayuda a las personas a seleccionar opciones, cambiar de vista y ordenar datos. Se suele ubicar después de un título de página o de grupo.
  • call_split
    Split button Los botones divididos abren un menú para ofrecer más opciones relacionadas con una acción.

Contención

  • horizontal_rule
    Divider Una línea de 1px en outline-variant: el contrato mínimo de la capa 3.
  • view_module
    Card Componente que contiene contenido y acciones que relacionan información sobre un tema.
  • list
    List Una superficie con filas en vertical. Cada fila tiene su altura, su forma y su color, y puede estar seleccionada. · Un par
  • view_quilt
    Scaffold Estructura base de pantalla que organiza y ensambla las regiones de navegación, cabeceras y contenido.
  • dashboard_customize
    Layout Patrones canónicos de distribución interior de Material Design 3: Rejilla responsiva fluida, Feed adaptativo y contenedor acotado.

Comunicación

  • notifications_active
    Badge El badge es un indicador no interactivo: notifica actividad (dot) o cuantifica pendientes (pastilla) sobre el componente anfitrión.
  • chat
    Dialog Componente que ofrece avisos importantes en un flujo de usuario. Puede requerir una acción, comunicar información o ayudar a completar una tarea.
  • info
    Snackbar El snackbar informa sobre una operación o el resultado de una acción de bajo impacto sin bloquear la navegación.
  • progress_activity
    Loading Indicator Indicador de progreso indeterminado con morfología viva entre las 7 figuras canónicas de Material Design 3 Expressive.

Navegación

  • title
    Top App Bar Cabecera de navegación superior con titular y subtítulo.
  • tab
    Tabs Las pestañas permiten navegar entre subpaneles dentro de un mismo contexto, con un indicador activo en la base.
  • dock_to_bottom
    Navigation Bar Barra inferior de navegación primaria de 80dp: reparte de 3 a 5 destinos en flex y señala el activo con la pastilla del active indicator.
  • view_sidebar
    Navigation Rail Carril vertical primario M3 Expressive: 96dp colapsado y 280dp expandido con pastilla activa continua y cabecera adaptable.

Selección

  • tag
    Chip El chip ayuda a las personas a representar opciones, filtros y entradas de datos en una sola píldora táctil. Se suele ubicar dentro de tarjetas, filas o barras de acciones.
  • toggle_on
    Switch Los conmutadores (Switches) alternan el estado de una sola configuración entre activado y desactivado.
  • check_box
    Checkbox Las casillas de verificación (Checkboxes) permiten a las personas seleccionar uno o más elementos de una lista, o alternar un estado binario o indeterminado.
  • radio_button_checked
    Radio Button Los botones de radio (Radio Buttons) permiten a las personas seleccionar una sola opción de un conjunto.
  • arrow_drop_down_circle
    Select Los selectores permiten a las personas elegir una opción de una lista.
  • more_vert
    Menú Superficie flotante elevada que presenta una lista vertical de opciones o acciones sobre el contenido anfitrión.
