Divider

Una línea fina que separa contenido relacionado dentro de un contenedor, como los elementos de una lista o las secciones de una tarjeta.

Uso

Cuándo usarlo

  • Para agrupar visualmente elementos de una lista sin añadir peso.
  • Para separar secciones dentro de una misma superficie, como una tarjeta o un menú.

Cuándo no usarlo

  • Para separar secciones de una página completa: ahí el espacio en blanco ya cumple esa función.
  • Entre elementos que ya están separados por contenedores o fondos distintos.

Default

Contenido encima del divisor.

Contenido debajo del divisor.

Variaciones

Color

Shapes

Este componente no tiene shapes: es una línea recta sin esquinas.

Sizes

Este componente no tiene tamaños: su grosor es fijo (--md-sys-shape-stroke-thin).

Padding

Este componente no tiene configuraciones de padding propias. La separación lateral se muestra en Variaciones (inset y middle inset).

States

Este componente no tiene estados.

Anatomía

  1. Línea: el pseudo-elemento ::before, que toma el color del elemento con currentColor.
