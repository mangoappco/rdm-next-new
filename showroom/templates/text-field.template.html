RDM ManGo! App

Text Field

Campo de texto estructural M3 para entrada de datos. Variante Outlined con label flotante CSS-only (sin JS), notch automatico y estados interactivos.

Especificacion tecnica y anatomia

Base & anatomy

Outlined Text Field en reposo estructural con label flotante gobernado 100% por CSS (:focus-within y :not(:placeholder-shown)), sin JavaScript.

Ingresa el nombre visible en el catálogo 
<div class="md-text-field md-text-field-outlined">
  <div class="md-text-field-container">
    <input type="text" class="md-text-field-input" id="tf-base" placeholder=" " aria-describedby="tf-base-supporting">
    <label class="md-text-field-label" for="tf-base">Nombre del producto</label>
    <span class="md-text-field-outline" aria-hidden="true"></span>
  </div>
  <span class="md-text-field-supporting-text" id="tf-base-supporting">Ingresa el nombre visible en el catálogo</span>
</div>

Par 2 · Icon slots (Leading + Trailing)

Campo Outlined con iconos leading (search) y trailing (tune) contextuales. Padding lateral 12dp (space-150) con iconos, gap icono-texto 16dp (space-200). Label se reposiciona a 52dp (12+24+16). Iconos cambian a color primary en focus y error en estado de error.

Par 3 · Supporting text, Helper & Error states

Campo Outlined en estado de error (clase .md-text-field-error + aria-invalid="true"). Outline 2px error, label error, supporting text error, iconos error, counter error. Supporting row con aria-live="polite" para anuncio AT. Helper text y counter en la misma fila con gap 8dp.

Par 4 · Filled variant

Filled Text Field: mismo HTML que Outlined, solo cambia la clase raíz. Fondo surface-container-highest, esquinas asimétricas (4dp arriba, 0dp abajo), active indicator inferior (1px reposo → 2px focus/error). Label sin notch (fondo surface-container-highest). Iconos, supporting text y error states idénticos a Outlined.
