Text Field

Campo de texto estructural M3 para entrada de datos. Variante Outlined con label flotante CSS-only (sin JS), notch automatico y estados interactivos.

Especificacion tecnica y anatomia

Base & anatomy

Outlined Text Field en reposo estructural con label flotante gobernado 100% por CSS (:focus-within y :not(:placeholder-shown)), sin JavaScript.

Par 3 · Supporting text, Helper & Error states

Campo Outlined con validación interactiva HTML5 nativa (Constraint Validation API). Al escribir, el counter se actualiza en tiempo real (longitud/maxlength). Al desenfocar un campo sucio e inválido, se añade .md-text-field-error, el ícono de error se activa en el trailing slot, el outline vira a 2px error y el helper text se permuta al mensaje de error. Gobernado por la Constraint Validation API y CSS-only para los estados visuales.

Par 4 · Filled variant

Filled Text Field: mismo HTML que Outlined, solo cambia la clase raíz. Fondo surface-container-highest, esquinas asimétricas (4dp arriba, 0dp abajo), active indicator inferior (1px reposo → 2px focus/error). Label sin notch (fondo surface-container-highest). Iconos, supporting text y error states idénticos a Outlined.

Par 10 · Readonly state

Campo de texto de solo lectura con el atributo nativo readonly. Mantiene el 100% de opacidad y contraste, cursor de selección (permite Tab, posicionar cursor y copiar), y conserva el trazo de reposo en 1px durante el foco para comunicar que no admite edición. Gobernado 100% por CSS con :has(.md-text-field-input:read-only), sin clases cosméticas en el contenedor.
