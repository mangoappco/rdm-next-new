Icon button

Componente interactivo compacto diseñado para ejecutar acciones con un solo clic donde el símbolo visual es autosuficiente para comunicar el significado.

Clase base

La clase base sola: sin relleno, sin borde, tamano small (40). Es el estado cero del que salen las otras tres.

Navegación

M3 permite el mismo componente como enlace cuando navega: cambia <a> por <button> y type por href. Sin diferencias de estilo. href es obligatorio: sin el no hay enlace, no es enfocable con el teclado, y :disabled no existe para enlaces (si hay que deshabilitar, es un boton).
