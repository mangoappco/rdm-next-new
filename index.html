Filosofia y Reglas No Negociables

Este proyecto implementa un showroom de alta fidelidad para ManGo! App, basado en la especificacion oficial de Material Design 3.

El desarrollo sigue una estricta jerarquia de 3 capas:

  • Capa 1 (Ref): Primitivas fisicas agnosticas (paletas, escalas, tiempos).
  • Capa 2 (Sys): Roles semanticos de negocio y tema (colores, formas, tipos).
  • Capa 3 (Comp): Recetas de componentes atomicos.

ManGo! App SAS (c) 2026 — Demostrador de Componentes M3

Divider

Una linea horizontal que separa contenido dentro de un contenedor.

Uso

Usa un divisor cuando necesitas separar visualmente bloques de contenido que pertenecen a un mismo grupo, sin usar un borde de caja ni una sombra.

Es el separador mas ligero del sistema: no tiene fondo propio, toma el color del contexto y mide 1px de grosor.

Ejemplo basico

La forma mas simple: un <hr> con la clase del componente.

Variantes

M3 define tres variantes segun la separacion lateral:

  • Full-width — sin inset. Ocupa todo el ancho disponible.
  • Inset — 16dp de padding a la izquierda, 0 a la derecha.
  • Middle-inset — 16dp de padding en ambos lados.

Color

El divisor usa el rol outline-variant, un gris violeta atenuado que funciona en ambos temas.

No tiene color propio: aplica color al elemento y el ::before lo toma con currentColor. Asi hereda el color del contexto.

Padding

Las variantes inset y middle-inset anaden padding lateral. Los valores vienen del token --md-sys-measurement-inset:

  • Full-width — 0 / 0
  • Inset — 16dp / 0
  • Middle-inset — 16dp / 16dp

Comportamiento

El divisor no responde a interaccion: no tiene estados :hover, :focus ni :disabled.

Su unico comportamiento es pasivo: hereda el color del contexto. Si un contenedor tiene color: primary, el divisor que contiene se ve primario sin clases extra.

Anatomia

El componente entero son dos reglas:

  • .md-divider — el contenedor. Pone el color, el grosor y el ancho.
  • ::before — la linea visible. Toma el color con currentColor.

Accesibilidad

El elemento obligatorio es <hr>. El <hr> nativo tiene role="separator" implicito, asi que un lector de pantallas lo anuncia como un separador.

Si usas <div> en su lugar, pierdes ese rol y el divisor se vuelve invisible para un lector de pantallas.

Composicion

El divisor se usa dentro de listas y tarjetas para separar elementos. Aqui un ejemplo en una lista:

Do / Don't

Do

  • Usa <hr> para mantener la semantica.
  • Usa las variantes inset cuando el contenido tiene un icono o avatar alineado.

Don't

  • No uses <div> sin semantica: pierdes el rol de separador.
  • No uses el divisor como borde de caja: para eso esta .md-border-*.

Medidas

Valores del componente y de su contexto de uso, segun la especificacion de M3:

  • Grosor — 1px (--md-sys-shape-stroke-thin)
  • Ancho — 100% del contenedor
  • Inset — 16dp (--md-sys-measurement-inset)
  • Espacio con texto — 4dp
  • Margen derecho — 8dp
  • Margen inferior — 8dp

Tokens

El componente consume tres tokens de 2-sys/:

  • --md-sys-color-outline-variant — color de la linea
  • --md-sys-shape-stroke-thin — grosor de 1px
  • --md-sys-measurement-inset — inset lateral de 16dp

Declara ademas dos tokens de componente: --md-comp-divider-color y --md-comp-divider-thickness.
